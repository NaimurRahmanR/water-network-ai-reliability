# AQUA-VERA Held-Out Test Evaluator v0.7b

## Why v0.7 failed

The frozen GCN-GRU checkpoint was valid.

The v0.7 evaluator reconstructed the same numerical architecture using different
Python module attribute names:

v0.7 evaluator:
- g1
- g2
- r
- h

Frozen training model:
- gcn1
- gcn2
- gru
- head

PyTorch `state_dict` keys include those names, so strict checkpoint loading
correctly failed.

No predictions or test metrics were generated by v0.7.

## v0.7b correction

v0.7b uses the exact training-time class/module names.

It also fixes the NumPy adjacency-normalization warning caused by:
`np.power(..., where=...)` without an initialized `out`.

Most importantly, v0.7b now verifies BOTH frozen checkpoints and the reconstructed
GCN adjacency buffer BEFORE loading held-out test contexts.

The frozen model checkpoints and frozen thresholds are unchanged.
