# BattLeDIM external-validation results

This directory mirrors the frozen summaries available when the GitHub-ready repository was assembled.

The final v0.16b and v0.17 summaries contain SHA-256 hashes for their full local artifacts. The exact raw output directories were not uploaded into this workspace, so they are not silently reconstructed here.

Use `tools/collect_external_artifacts_windows.bat` on the original experiment machine to collect those exact frozen output directories for a later commit.
