# Results

`net3/` contains the frozen Net3 result artifacts used for the reported findings,
including model checkpoints, raw prediction tables, degradation manifests,
attribution profiles, reconstruction outputs, and controller outcomes.

`battledim/` contains the BattLeDIM/L-Town discovery/protocol/training/final-evaluation
summaries that were available in this project record. The complete local v0.16b and
v0.17 raw output directories were not uploaded into this workspace, so this repository
does not fabricate them. Their recorded artifact hashes remain in the corresponding
frozen summaries.

`summary/` contains compact tables for quick inspection.
