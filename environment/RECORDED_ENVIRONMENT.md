# Recorded environment

- Python 3.12.2
- Windows 11
- NumPy 2.5.0
- pandas 3.0.3
- PyTorch 2.11.0+cpu
- WNTR 1.5.0

Later stages also use scikit-learn and NetworkX. Their exact historical versions were not preserved in the available records, so they are left unpinned rather than reconstructed from memory.
